 Temperature Converter

A simple web app built for Task 3 (Level 1) of the Oasis Infobyte Web Development Internship.

 Features
- Converts temperatures between Celsius, Fahrenheit, and Kelvin.
- Checks for invalid entries and temperatures below Absolute Zero.
- Works smoothly without reloading the page.
- Fully responsive design for desktop and mobile.

 Built With
- HTML5
- CSS3
- JavaScript

 Formulas Used
- Celsius to Fahrenheit: F = (C * 9/5) + 32
- Celsius to Kelvin: K = C + 273.15
- Fahrenheit to Celsius: C = (F - 32) * 5/9
- Fahrenheit to Kelvin: K = ((F - 32) * 5/9) + 273.15
- Kelvin to Celsius: C = K - 273.15
- Kelvin to Fahrenheit:** F = [(K - 273.15) * 9/5] + 32

 How to Run
1. Open "index.html" in any web browser.
2. Enter a temperature, pick a unit, and click Convert.
